# LocalFlow v0.4 — Outline

**Status: outline only, 2026-11-04.** Gets a full plan when v0.3 is finished.

**Goal:** a Smart mode that cleans up text with a local LLM, without changing what the user meant. The owner decided on 2026-11-04 that
the LLM is part of v1.0, so the question is how to add it safely, not whether.

**Decided (owner, 2026-11-04)**
- The default stays rule-based cleanup (Light). Smart is an option, and only becomes the default if it passes the safety check.
- On 8 GB Macs such as the MacBook Neo, Smart is off by default. The owner has no 8 GB Mac, so that's untested unless a tester has one.
- Local only, never an API.

**Safety check, before building it into the app**
1. Write the pass line first, with the owner, before seeing results. Meaning damage is what matters most.
2. Run the candidate offline with `mlx-lm` on `bench/cleanup_cases.tsv`, after filling `expected_smart`.

Fixes alone can't judge this. People don't fix text that was understood anyway, so fixes undercount errors, and they can't show what an
LLM would have done.

**Starting points** (`docs/plans/v0.2.md` §7): Qwen3-1.7B 4-bit with MLX Swift, thinking off; a subsequence guardrail instead of
length only; a timeout proportional to length; preload about 300 ms into a hold; Replacements before and after; verify unload frees
memory; memory use alongside Whisper on 8 GB.
