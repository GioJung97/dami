# Dami v1.0 — Implementation plan

**Status: done (2026-11-08), merged to `main` as 1.0.0. Already in `v1.0` before M1: the
rename to Dami, the JD2 design and the quick tour. M1–M5 done (2026-11-08), except the accessibility checks in M5.**

**Goal:** anyone on an Apple Silicon Mac can install Dami and trust it. No new features: finish, package, and try it on other
Macs and other people. The done list is `PLAN.md` Roadmap, "v1.0 is done when".

**Principle:** as before, losing speech, pasting wrongly or breaking trust stops other work. Anything found along the way goes in
`docs/known-issues.md` or the not-scheduled list, unless it's one of those.

## 2. Out of scope

New features, Smart mode, account sign-in and sync themselves, notarization, the App Store, Intel Macs, automatic updates. Fixes for
known issues other than the detection one, unless they lose speech, paste wrongly or break trust.

## 3. Working rules

As in `CLAUDE.md`: a milestone at a time, the owner tests in the real app before each commit, `scripts/health-check.sh` at the end of
each milestone, never print or change the real database, ask before any push, merge or publish. **A GitHub Release publishes a
download to anyone, so it's asked for separately, each time.**

### M1 — Screens that promise what isn't coming

- **First, AirPods (found 2026-11-08, it lost speech):** starting the mic while a Bluetooth headset switches to its call mode
  failed or recorded nothing, and the built-in mic failed while AirPods were the default. Fixed in `AudioRecorder`, see
  `docs/known-issues.md` "Bluetooth microphones".

- Home's "Learned from your edits" card: say what it does now (fixes in History and where you pasted, suggestions you approve), and
  show how many suggestions are waiting, with a link to Dictionary › Suggestions.
- Settings › Sync: reworded as an account that syncs, still "Coming later".
- Settings › Speech model › "Cleanup model": removed.
- Setup: after Allow in macOS's Microphone prompt, bring the setup window back to the front.
- Learn from fixes on a huge field: measure how long reading and comparing a long Terminal buffer takes, once a second on the main
  thread (v0.3.1 review). If it can be felt, stop watching above a size. Measured on made-up text, never the owner's terminal.

**Owner test:** look at Home and Settings, and open the link. Reset setup and allow the microphone: setup comes back to the front.

### M2 — Language detection encodes once

- Detection keeps the encoder's output, and transcription uses it instead of encoding again. A retry with padding or without the
  prompt still encodes its own audio.
- Check that detection picks the same language as before on recorded clips, and the latency samples show detection about 0.4 s
  shorter. Clips: the 30 from the second Mac.

**Owner test:** dictate as usual in Auto, Korean, English and mixed, for a while. It should feel a little faster and get the language
right as before.

### M3 — Diagnostics export

- A button in Settings › Privacy (or About) saves a text file, and shows it before saving. It holds numbers only: app and macOS
  version, Mac model and memory, languages and settings chosen, failure and drop counters, retry results, stage times of the last
  dictations, database health, whether there were crash reports. Never dictated text, Dictionary entries, or which key was pressed.
- The owner reads the first file before any tester gets the app.

**Owner test:** export, read the file, check there's nothing in it you wouldn't send.

### M4 — The `.dmg`

- `scripts/release.sh`: a Release build signed as today, in a `.dmg` with the app and a link to Applications. Version from
  `project.yml`.
- README: Install already comes first (design). Add the `.dmg` download and the "Open Anyway" steps for the first launch; building
  from source stays below it.
- Check: the app inside the `.dmg` is signed, and the same certificate as the installed one, so permissions carry over.

**Owner test:** install from the `.dmg` on this Mac over the current app. Permissions are kept and dictation works.

### M5 — Install on the second Mac

- Copy the `.dmg` to the second Mac the way a tester would get it (downloaded, so macOS marks it as from the internet).
- Go through: open, allow in System Settings, onboarding, model download, dictate in two apps. Then install the next build over it and
  check permissions stay.
- This also checks the open items in `docs/known-issues.md` "First-run setup" that need another Mac, and on this first install:
  - the quick tour starts right after setup;
  - the HUD shows on the first recording right after setup, with the model downloaded fresh ("HUD not visible", 2026-11-07);
  - after Allow in the Microphone prompt, whether setup has to be brought back to the front.
- With the new look and the tour: VoiceOver, Reduce Motion and Increase Contrast. These can run on this Mac too.

**Owner test:** the steps above, with a short list written for it.
