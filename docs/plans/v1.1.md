# Dami v1.1 — Plan

**Status: released as 1.1.0 (owner, 2026-11-17).** Built 2026-11-15, in daily use for two days before release.

**Goal:** two fixes found in everyday use of 1.0.0. No new features.
1. The HUD showed on one desktop only (`docs/known-issues.md`, 2026-11-12).
2. A mixed dictation sometimes came out all in one language (`docs/known-issues.md`, 2026-11-09).

**Principle:** as before, losing speech, pasting wrongly or breaking trust stops other work. Anything else found goes in
`docs/known-issues.md`.

---

## 1. Decided

**Owner, 2026-11-12 and 2026-11-15**

| Question | Decision |
|---|---|
| HUD fix | A new panel each time the HUD hides (committed first on `v1.0.1`, `2fed87e`, then brought into `v1.1`). `v1.0.1` is not released on its own |
| How to design language choice | General, not fitted to the owner's voice: public data only (HiKE, CS-FLEURS read, FLEURS), one setting for every language, tuned on ko, zh, es, de and checked on ja, fr, pt, hi, vi. The owner's recordings are only a last sanity check |
| Language choice | When detection is unsure (English minus second-language score in −3..7), transcribe in both and keep the text Whisper is more confident of. The extra run gets no temperature fallback and is dropped if it fails Whisper's quality check |
| Release | After a few days of daily use, not right away |

## 2. Out of scope

- Splitting a dictation into parts by language. Next candidate if sentence-level switching still fails, not planned.
- A "try the other language" button in History. Not decided.
- Errors that no language choice fixes (CS-FLEURS Korean and Japanese read speech stay at about 8–10% severe). Not looked into.

## 3. What was built

- `Dami/UI/HUD/HUDController.swift`, `Dami/UI/Tour/MenuBarSpotlight.swift`: new panels after hiding.
- `Dami/Transcription/Transcriber.swift`: detection returns its margin; unsure → both runs, pick by mean log probability per text
  token. `Dami/Core/DictationProcessor.swift`: the latency log gains `compared=` and `switched=`.
- `bench/lideval` (Swift, runs the app's model on manifests), `bench/lid_manifest.py`, `bench/lid_score.py`, `bench/lid_select.py`;
  results in `bench/lid_results.md`. Datasets stay out of git (`bench/data/`).

Measured (public data, read speech, 1–4 speakers per language pair): severe failures among unsure clips 3.4% → 1.4% on the tuning
languages, 4.1% → 3.4% on the held-out ones, no language worse. Clear cases are unchanged. Extra time when unsure: about 0.8 s.
