## M3: schema v3, Fix in History

- **Owner's decisions (2026-11-05):** a fixed dictation shows the fix first, with the pasted text small below it, and search, Copy and
  paste again use the fix. Recent rows get a pencil on hover that opens History with the fix box. "This is what I said" shows only
  with saved audio, marks the text shown now, and a new fix clears it. A marked dictation is kept past both text and audio retention,
  until it's unmarked or deleted. A database that can't open shows "History isn't being saved" at the top of the menu, with the reason
  on click.
- **Migration v3:** `fixedText`, `confirmedAt`, `confirmedText` on `dictation`, plus `edit` and `pasteWatch` tables that are deleted
  with their dictation. Before any migration the app copies the file to `LocalFlow.backup.sqlite`, and a failed copy stops it.
- **Checked on a copy first** with a scratch program around the real `Store.swift`: 225 dictations, 8 terms and 3 replacements hashed
  the same before and after, new columns null on old rows, the backup matching. 19 behaviour checks passed on synthetic rows, including
  retention and the broken-database reason. The real database then migrated with the same hash. The copy was deleted.
- **Owner tested:** fixing in History, Copy, search, the Recent pencil, Recent showing and pasting the fix, the mark and Unmark, normal
  dictation. **Not tested in the app:** the menu warning, which needs a database that won't open.

## M4: suggestions

- **Owner's decisions (2026-11-05):** one fix gives at most one suggestion, a Replacement, when 1–3 words changed on each side. Deletions,
  additions and bigger rewrites give none. It shows under the fix in History: "Always fix X → Y?", with how many past dictations have the
  word and a few of the words it would touch. Only future dictations change. "Not this" isn't asked again. Dictionary › Suggestions,
  which said "Coming in a later update", now lists unanswered and declined suggestions, with "Ask again".
- **Korean particles:** for a one-word change, a known particle both sides share is dropped, so "로컬플로우로" → "LocalFlow로" learns
  "로컬플로우" → "LocalFlow". Shared verb endings are kept.
- **Vocabulary cap:** WhisperKit keeps only the last 111 prompt tokens, which could cut a term in half. The prompt now holds whole
  terms, newest first, and Dictionary marks terms that don't fit as "Not in the hint".
- **Migration v4** adds the `suggestion` table. Checked on a copy first, all rows hashed the same, then the real database the same.
- **Owner tested:** a suggestion after a fix, the preview, Always fix creating a Replacement that changed the next dictation, Not this,
  Ask again, no suggestion for deletions and rewrites. **Not seen in the app:** the "Not in the hint" mark, since the list is short.
