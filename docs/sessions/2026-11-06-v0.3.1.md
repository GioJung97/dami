# Session notes — v0.3.1, 2026-11-06

Work on branch `v0.3.1`, following `docs/plans/v0.3.1.md`.

## M1: a stray key doesn't discard a recording

- `HotkeyMachine` keeps when a modifier-only press started. A key down within 1.0 s still cancels, as an app shortcut. A later one
  does nothing to the recording, so the release still ends it. The time comes from `systemUptime` by default; tests pass their own.
- Tests: within and after the window, key repeat, the window restarting on the next press, LocalFlow's own ⌘V, key shortcuts
  unchanged. 118 pass, cleanup eval 0 `must_keep` changed, health check showed nothing new.
- **Owner tested (2026-11-06):** Space halfway through a held recording, and the whole sentence pasted. A key right after the press
  cancelled with nothing pasted.

## M2: Replacements only change whole words

- **Korean:** a Hangul rule needs no Hangul right before it, and after it the end of the word or up to two particles. The particle
  list moved to `KoreanParticles`, shared with suggestions. A one-syllable Hangul `find` is never suggested.
- **Added (owner, 2026-11-06):** every spaced language now matches whole words, ignoring case. Before, only plain a–z did, so an
  accented or Devanagari rule matched inside words ("más" also changed "demás"). Japanese, Chinese and Thai still match anywhere. A
  word also ends at Hangul, so "cloud code로" still matches "cloud code".
- Two old tests expected the old behaviour (suggesting "세 → 네", previewing "제안서를") and were updated. 132 tests pass, cleanup eval
  0 `must_keep` changed. The eval can't carry a rule, so the "확인하세요" case is a unit test.
- The owner's 3 Replacements had never fired, so nothing seen so far changes.
- **Owner tested (2026-11-06):** a hand-made "세 → 네" rule changed "세 시에 봐요" and left "확인하세요" alone. A one-syllable fix
  ("그" → "이") gave no suggestion.
- **Learned while testing:** Whisper writes "세 시에" as "3시에", so the first one-syllable test gave "3시 → 네시", which is
  allowed. Test sentences for one syllable should avoid numbers. "100이야 → 필기야" showed a suggestion with digits can be a real
  mishearing, so digits aren't blocked.
